# StrangeMods · 奇奇怪怪的 MOD 库

本仓库用于存放已完成的 Minecraft MOD 打包成品（JAR 文件），点开即可直接下载。

> 注意：GitHub 仓库名不支持中文，故使用 **StrangeMods**，中文含义为「奇奇怪怪的 MOD」。

## 环境要求（当前所有 MOD 通用）

| 项目 | 要求 |
| ---- | ---- |
| Minecraft | 1.21.1 |
| 模组加载器 | NeoForge 21.1.x（推荐最新版） |
| Java | 21 |

## 收录的 MOD

### 必死图腾（BisiTotem）

> Totem of Certain Death - saves you, then dooms you.

一个「会救你，然后杀死你」的不死图腾：触发时替你挡下致命伤害，随后带来必死的诅咒。

| 文件 | 版本 | 下载 |
| ---- | ---- | ---- |
| [bilibili]bisitotem-1.21.1-2.0.1.jar | 2.0.1 | [点击下载](https://github.com/HongTangChen07/StrangeMods/raw/main/%5Bbilibili%5Dbisitotem-1.21.1-2.0.1.jar) |

## 安装方法

1. 点击上表「下载」链接，获取 JAR 文件；
2. 将 JAR 放入游戏版本的 `mods` 文件夹（若使用 PCL2 / HMCL / 官方启动器，在版本设置的 mods 目录中）；
3. 启动游戏（需已安装对应版本的 NeoForge）；
4. 进入游戏后，物品会出现在创造模式物品栏的对应标签页中。
