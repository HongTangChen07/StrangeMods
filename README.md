本仓库用于存放已完成的 Minecraft MOD 打包成品（JAR 文件），点开即可直接下载。

> 注意：GitHub 仓库名不支持中文，故使用 **StrangeMods**，中文含义为「奇奇怪怪的 MOD」。

<summary><b>🍎 祛魔金苹果（DisenchantGoldenApple）· 详细介绍</b> <i>（点击展开）</i></summary>

> 给金苹果附上各种奇奇怪怪的附魔，吃下去触发对应的效果。BUFF 强度取决于你附了什么书。

### 两种金苹果

| 物品 | 获取方式 | 定位 |
| ---- | ---- | ---- |
| **可附魔金苹果** | 9 个金苹果无序合成 | 丐版：BUFF 等级最高 2，3 级附魔只增加时长 |
| **祛魔金苹果** | 原版附魔金苹果放进**砂轮**「祛魔」获得 | 完整版：支持 3 级附魔的完整效果 |

### BUFF 规则（吃下附魔金苹果后）

- **祛魔金苹果**：3 级附魔 → 满时长满等级；2 级 → 时长减半、BUFF 2 级；1 级 → 与 2 级相同时长、BUFF 1 级
- **可附魔金苹果**：3 级附魔 → 时长增加但 BUFF 最高 2 级；2 级 → 时长更短、BUFF 2 级；1 级 → 与 2 级相同时长、BUFF 1 级

### 祛魔附魔台（新方块）

专属附魔台，用**燃料**给附魔书附魔：

- **只能附出 1-2 级附魔书**，3 级必须在铁砧合成
- **18 级**经验解锁 1 级附魔（附魔后扣 3 级）、**30 级**解锁 2 级（附魔后扣 5 级）
- 燃料 → 附魔映射示例：TNT→爆炸、蜘蛛眼→剧毒、糖→急速、烈焰粉→力量、恶魂之泪→再生……
- 需要**铁镐**挖掘
- 📖 完整 44 种燃料配方见：[附魔书配方表](https://github.com/HongTangChen07/DisenchantGoldenApple/blob/main/%E9%99%84%E9%AD%94%E4%B9%A6%E9%85%8D%E6%96%B9%E8%A1%A8.md)

### 铁砧规则

- **两本本 mod 的 2 级附魔书 → 3 级书**，消耗 **15 级**经验（照原版附魔合并逻辑，同级 +1）
- 附魔书只能附在本 mod 的两类金苹果上；**原版金苹果、原版附魔书一律禁止**
- 金苹果铁砧成本封顶 **30 级**（不再增长），其他物品封顶 40 级

### 40+ 种自定义附魔

效果附魔（爆炸、剧毒、急速、力量、再生、抗火、跳跃、夜视、水下呼吸、缓慢坠落……）、负面附魔（虚弱、反胃、失明、挖掘疲劳……）与诅咒；附魔之间遵循**互斥规则**（附魔台/铁砧时自动规避冲突）。

吃下后按附魔触发对应效果：落雷、爆炸、药水效果……其中「**万箭穿心**」会在效果期间自动生成**箭雨射向目标**，等级越高轮数越多、每轮箭数越多。

### 祛魔

原版附魔金苹果 → 砂轮 → **祛魔金苹果**（消耗附魔金苹果，无经验返还）。

<summary><b>💀 必死图腾（BisiTotem）· 详细介绍</b> <i>（点击展开）</i></summary>

> Totem of Certain Death - saves you, then dooms you.

一个「会救你，然后杀死你」的不死图腾：替你在致命时刻挡下伤害，随后开启一场不可逆转的死亡倒计时。

### 物品一览

本模组共 5 种图腾，主手或副手持有，受到致命伤害时自动触发。

| 物品 | 稀有度 | 一句话介绍 |
| ---- | ---- | ---- |
| 必死图腾 | 普通 | 救你一命，然后给你死刑 |
| 特制必死图腾 | — | 爆炸开场，爆炸收场，附带同归于尽 |
| 狂暴必死图腾 | 史诗 | 一分钟的无敌与毁灭，然后燃尽自己 |
| 不死图腾（伪） | — | 「看起来有点奇怪」的假图腾 |
| 不死图腾（伪·特制） | — | 「更奇怪了」的假图腾 |

#### 1. 必死图腾（BisiTotem）

**合成配方**（3×3 有序）：

```
玻璃  玻璃  玻璃
蜘蛛眼 金苹果 蜘蛛眼
煤炭块 煤炭块 煤炭块
```

**触发效果**：受到致命伤害时消耗 1 个图腾，替代死亡，并同时获得：

- **吸收 II**（5 秒）
- **再生 II**（45 秒）
- **防火**（40 秒）
- **必死**（死亡倒计时开始，见下）

触发时播放图腾使用音效，并伴随红黑色喷泉粒子与图腾动画。

**「必死」BUFF —— 死亡倒计时**：

- 一旦获得便**不可移除、不可过期**（牛奶、命令、死亡复活都清不掉，只有触发者真正死亡才会结束）；
- 会持续造成伤害，**每 30 秒伤害翻一倍**（第 1 阶段 5 点，第 2 阶段 10 点，第 3 阶段 20 点……），且**造成伤害的频率会逐渐加快**（从每 30 秒一次逐渐缩短到每 8 秒一次）；
- 死亡信息显示为「**XX 被刻意的游戏设计杀死了**」——这不是意外，是设计。

> 换句话说：图腾救你的那一刻起，你已经是死人，只是还剩多久的问题。

#### 2. 特制必死图腾（Special BisiTotem）

**合成配方**（3×3 有序）：

```
TNT  TNT  TNT
TNT  必死图腾 TNT
TNT  TNT  TNT
```

**触发效果**：触发时先给予 **1000 点吸收血量**（绝对死不了），紧接着：

1. 原地引爆 **12 格威力的 TNT 爆炸**；
2. 爆炸半径内所有生物（除你外）全部被挂上**「必死」**，并附带巨大的击飞；
3. 一切结束后，吸收血量清零，**你自己被"刻意的游戏设计"直接杀死**。

**可投掷**：右键可以像雪球一样把它扔出去，命中的位置引爆 12 格爆炸并让周围所有生物中「必死」；放入**发射器**同样可以发射。这也是一种远程整活手段。

#### 3. 狂暴必死图腾（FrenzyTotem）

**合成配方**（无序）：

```
特制必死图腾 + 不死图腾 + 金苹果 + 末地水晶
```

**触发效果**：受到致命伤害时消耗 1 个图腾，替代死亡，进入**「狂暴」**状态：

- **无敌**：60 秒内免疫一切伤害（伤害归零 + 生命兜底 + 死亡取消），任何攻击都无法杀死你；
- **毁灭**：攻击力 +60（约等于力量 V 的 20 倍）、移动速度 +100%，同时全身发光；
- **开场**：触发瞬间原地引爆 12 格 TNT，并给周围所有生物挂上「必死」；
- **倒计时**：60 秒狂暴结束后——以 24 格威力的 TNT 爆炸收场，随后受到「**燃尽**」伤害**强制死亡**（该伤害无视一切图腾与保护，直接死）；
- 狂暴中途被牛奶或命令移除也会**立刻触发同样的燃尽收场**，没有逃课选项。

图腾背面刻着古老的铭文：

> 「以爆炸与火焰为开场，以爆炸与火焰为结束。
> 一分钟后我将会死亡，而你，你将和我一起下地狱！」

死亡信息：「XX 燃尽了」。

#### 4. 伪不死图腾 / 伪特殊不死图腾（假图腾）

**获取方式**：与村庄的**牧师（神职人员）**交易——假不死图腾 20 绿宝石、假特殊不死图腾 30 绿宝石（均为 5 级交易，经验等级最高档）。

**合成伪装**：必死图腾（或特制必死图腾）+ **黄色染料**，即可伪装成普通的不死图腾，名字看起来完全一样，只有一行灰色小字：「看起来有点奇怪？」/「更奇怪了」。

**为什么做假图腾？**——坑人。把它送给别人，对方死到临头拿出来保命，结果……

- 假图腾**不能保命**，不会触发任何效果；
- 把假图腾放进**砂轮**想祛魔/还原？表面看会显示变回必死图腾，但**取出的一瞬间**会引爆 12 格 TNT、给周围所有人挂上「必死」、并把你（取出者）当场"刻意地"杀死；
- 真正的还原方法：假不死图腾 + **水桶 + 纸** 无序合成，得到必死图腾。

## 安装方法

1. 点击上表「下载」链接，获取 JAR 文件；
2. 将 JAR 放入游戏版本的 `mods` 文件夹（若使用 PCL2 / HMCL / 官方启动器，在版本设置的 mods 目录中）；
3. 启动游戏（需已安装对应版本的 NeoForge）；
4. 进入游戏后，物品会出现在创造模式物品栏对应的标签页中（祛魔金苹果 / 必死图腾）。
